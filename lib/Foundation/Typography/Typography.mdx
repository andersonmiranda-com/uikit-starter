# Typography

Type scales are hierarchical type systems consisting of style definitions for
common elements, such as Heading 1, Heading 2, Paragraph, Body and Body2.

Paris's type scale is based on the **Montserrat** typeface. The root font size
is 16px (1rem = 16px).
